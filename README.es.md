# Moshi · Marketplace Editions

**Conservar la skill modular y los documentos de cada edición de distribución.**

[English](README.md) · **Español**

Las ediciones de marketplace de la skill de acompañamiento emocional no profesional de Moshi. Estas copias difieren del repositorio moshi-skill ya publicado y conservan juntos sus módulos, alcance y condiciones de distribución.

## Qué cubre

| Área | Guía |
| --- | --- |
| Guía modular | Referencias separadas para cuidados, hábitos, adicciones, conflictos y resúmenes. |
| Memoria opcional | Guía para registros con consentimiento y una configuración separada de Docker/MongoDB. |
| Material de revisión | Fuentes, alcance multilingüe y casos ficticios de evaluación. |

## Primeros pasos

Leé [SKILL.md](SKILL.md) y después las referencias pertinentes. Dale a un agente compatible acceso al paquete y a los archivos autorizados. Conservá las carpetas adyacentes a SKILL.md; copiar solamente ese archivo puede romper sus referencias.

### Requisitos

Un agente compatible que pueda leer SKILL.md y las referencias adyacentes. Los flujos de memoria y PDF necesitan herramientas disponibles por separado; este paquete no las instala ni aloja.

### Ejemplo de pedido

> Revisá el paquete de marketplace como documentación. Identificá sus módulos, integraciones opcionales y evaluaciones pendientes sin iniciar una conversación de apoyo emocional.

## Alcance y límites

Apoyo experimental no profesional; no es tratamiento ni un servicio de emergencias. No se afirma eficacia clínica ni calidad equivalente entre idiomas. Los casos de evaluación son material de revisión, no evidencia de pruebas ejecutadas. Se conservan las condiciones originales de cada edición.

El README está disponible en inglés y español, como la documentación de Huella. Los SKILL.md y las referencias conservan su idioma y redacción originales.
